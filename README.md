# 🌍 Travel Website Template

This is a simple travel website template created using **HTML and CSS**.  
I built this project to practice front-end basics like layout design, styling, and page structure.  
It is beginner-friendly and easy to understand.

## 🔗 Live Demo
You can view the live website here:  
👉 https://syed450.github.io/desined-a-travelling-template-using-css-and-html/

## 🛠️ Technologies Used
- HTML5  
- CSS3  

## 🎨 Design & Font
- Clean and simple design
- Uses a **common system font** for better compatibility  
- Font used: **Arial, sans-serif**

This font is supported on almost all devices and browsers, making the website look consistent everywhere.

## ✨ Features
- Travel-themed layout
- Simple and clean UI
- Responsive structure
- Easy-to-read code for beginners

## 📁 Project Files
- `index.html` – Main webpage  
- `style.css` – Styling file  

## 🚀 How to Use
1. Download or clone this repository  
2. Open `index.html` in any web browser  
3. Customize the content or styles as you like
